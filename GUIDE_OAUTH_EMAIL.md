# 📧 Guide d'utilisation - Authentification et Email

## 🎯 Vue d'ensemble

chifak propose maintenant **3 moyens de connexion** :

1. **📧 Email + Code de vérification** (inscription classique)
2. **🔴 Google OAuth** (connexion avec Google)
3. **🔵 Facebook OAuth** (connexion avec Facebook)

---

## 📧 Inscription avec Email

### Pour s'inscrire :

1. Cliquez sur **"Connexion"** en haut à droite
2. Cliquez sur **"Créer un compte"**
3. Remplissez :
   - Nom complet
   - Email
   - Mot de passe (min 6 caractères)
   - Confirmation du mot de passe
4. Cliquez sur **"Créer un compte"**

### Vérification de l'email :

1. **Vérifiez votre boîte email** (regardez aussi dans les spams !)
2. Vous recevrez un email avec un **code à 6 chiffres**
3. Entrez ce code dans l'application
4. Cliquez sur **"Vérifier"**

✅ Votre compte est maintenant actif !

**Note :** Le code expire après **10 minutes**. Si le code a expiré, cliquez sur "Renvoyer le code".

---

## 🔴 Connexion avec Google

### Première connexion :

1. Cliquez sur **"Se connecter avec Google"**
2. Sélectionnez votre compte Google
3. Autorisez chifak à accéder à votre profil
4. ✅ Vous êtes connecté !

### Connexions suivantes :

Un simple clic sur "Se connecter avec Google" suffit !

**Avantages :**
- ✅ Pas besoin de mot de passe
- ✅ Connexion ultra-rapide
- ✅ Compte vérifié automatiquement

## 🔐 Sécurité

### Vos données sont protégées :

- ✅ Mots de passe **cryptés** (bcrypt)
- ✅ Tokens **sécurisés** (JWT)
- ✅ Code de vérification **unique** et **temporaire**
- ✅ OAuth **sécurisé** (protocole standard)

### Conseils de sécurité :

1. **Ne partagez jamais** votre code de vérification
2. Utilisez un **mot de passe fort** (si connexion par email)
3. **Déconnectez-vous** sur les ordinateurs publics
4. **Vérifiez toujours** l'expéditeur des emails (vérifiez que c'est bien chifak)

## ❓ Questions fréquentes

### Q : Je n'ai pas reçu le code de vérification
**R :** 
1. Vérifiez vos spams
2. Attendez 1-2 minutes
3. Cliquez sur "Renvoyer le code"
4. Vérifiez que l'email est correct

### Q : Le code a expiré
**R :** Cliquez sur "Renvoyer le code" pour recevoir un nouveau code.

### Q : Je veux changer mon email
**R :** Contactez le support (pour l'instant, créez un nouveau compte avec le bon email).

### Q : Puis-je utiliser Google ET Facebook ?
**R :** Oui ! Si vous utilisez le même email, les comptes seront liés automatiquement.

### Q : Comment me déconnecter ?
**R :** Cliquez sur votre nom en haut à droite, puis "Déconnexion".

### Q : Mes rendez-vous sont-ils sauvegardés ?
**R :** Oui ! Tous vos rendez-vous sont liés à votre compte (email).

### Pour une meilleure expérience :
